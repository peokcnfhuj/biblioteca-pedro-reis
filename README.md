# Biblioteca do Pedro Reis

A biblioteca de Pedro Reis — o acervo da Arcanum Academy, extensão da
Arcanum Academy, by PVSR Holding Tech.

Site separado da Biblioteca Arcanum Academy e do Projetos 3D. Acervo novo:
começa vazio (0 obras) — as 29 obras antigas ficam só na Biblioteca Arcanum
Academy. Só os livros novos que fizermos daqui pra frente entram aqui.
Mesma área de login (Supabase, projeto "arcanum-academy") e mesma leitura
com conta. Estética própria: preto estelar, azul como destaque principal
e cada livro com a sua cor.

- `index.html` — portal, busca, filtros, leitor nativo, portão de login,
  estado vazio ("O acervo está nascendo")
- `books-1.js`, `books-2.js`, `books-3.js` — dados de leitura (vazios por
  enquanto: `BOOKS_P1/P2/P3 = {}`)
- `supabase-config.js`, `supabase-auth.js` — área de login (mesmo projeto)
